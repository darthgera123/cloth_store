# The Price Is Right — Question Bank

One `## QUESTION-ID` block per product. Required fields: `Item:`, `Size:`,
`Image:`, `Price:` and `Source:`. Optional: `Description:`, `Currency:`
(default `INR`, enforced), `Unit:` (default `item`), `Category:`,
`Difficulty:` (`easy`, `medium`, `hard`).

`Price:` is the fixed game reference price in INR, shown only after the host
reveals it. `Image:` is a locally hosted photograph in `public/products/`
(resolved against the deployed base path). `Source:` records the product page
the price and photograph were taken from.
