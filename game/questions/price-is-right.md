# The Price Is Right — Question Bank

One `## QUESTION-ID` block per item. Required fields: `Item:`, `Description:`,
`Image:` and `Price:`. Optional: `Currency:` (default `INR`), `Unit:` (default
`item`), `Category:`, `Difficulty:` (`easy`, `medium`, `hard`).

`Price:` must be the true price shown only after the host reveals it.
