# Family Feud — Question Bank

One `## QUESTION-ID` block per question. Keep the ID stable once it has been
used; it is what the host stores for the selected rounds.

Each question needs:

- `English:` the question as read aloud.
- `Hindi:` the same question in Hindi/Hinglish.
- A markdown table with the columns `Points | Hindi | English`, exactly five
  rows, points adding up to 100, in the order the answers should be revealed.

Optional: `Category:` and `Difficulty:` (`easy`, `medium`, `hard`).
